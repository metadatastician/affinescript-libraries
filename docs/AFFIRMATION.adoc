== The honest state (one breath)

At the anchor this is a design-stage repository. The KYAML lexer, AST and parser exist as
1,375 lines of AffineScript in four files, and none of them parses under the current
compiler. The build and test recipes are placeholders and do not run under the current
`just`. The repository's CI is healthy: all seven workflows that run on `main` start and
pass.

=== The honest nuance you must not lose

* *rust-ci passing is not a Rust test.* There is no `Cargo.toml`. Its detect job succeeds
  and the four Rust jobs are skipped.
* *"PASS" in the Justfile is printed text.* `test-kyaml` runs `echo "KYAML tests: PASS
  (placeholder)"`. `build-kyaml` copies the sources and writes a stub file. Neither
  invokes a compiler.
