== What this is

AffineScript Libraries is a collection of reusable libraries for the
https://github.com/hyperpolymath/affinescript[AffineScript] programming language.

This repository provides:

* **KYAML Processing** — Kubernetes-native YAML parsing, querying, and manipulation
* **Query Languages** — jq-like and custom query DSLs for data extraction
* **Lint Rules** — Pluggable linting infrastructure for Kubernetes manifests
* **Utility Libraries** — Common data structures and algorithms
* **FFI Bindings** — Foreign function interfaces for interoperability

== Quick start

[source,bash]
----
# Clone the repository
git clone https://github.com/metadatastician/affinescript-libraries.git
cd affinescript-libraries

# Build all libraries
just build

# Run tests
just test

# See available libraries
ls src/
----

| `Data/` | Generic data structures (maps, sets, vectors)
| `Text/` | Text processing and parsing utilities
| `Json/` | JSON serialization/deserialization
| `Yaml/` | Generic YAML support (non-K8s)
|===

== Usage with kcq

This library is the upstream source for the kcq tool's core functionality.
The https://github.com/metadatastician/kcq[kcq] tool uses libraries from here.

To use these libraries in your own AffineScript project:

[source,affine]
----
import Kyaml
import Kyaml.Query
import Kyaml.Lint.RequiredFields

// Parse and lint a Kubernetes manifest
let content = readFile "deployment.yaml"
let result = Kyaml.parse content

match result with
| ParseSuccess file ->
    let issues = Kyaml.lintFile content
    if issues != [] then
      printIssues issues
    else
      let json = Kyaml.toJson file
      print json
| ParseFailure errors ->
    printErrors errors
----
